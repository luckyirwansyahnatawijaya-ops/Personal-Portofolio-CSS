# Personal Portfolio CSS

A responsive multi-page personal portfolio built with semantic HTML5 and vanilla CSS, created for the [roadmap.sh Frontend Developer](https://roadmap.sh/projects/portfolio-website) track.

**Live Site:** https://luckyirwansyahnatawijaya-ops.github.io/Personal-Portfolio-CSS/

## Pages

- `index.html` — Overview, featured projects, experience, education, and peer reviews laid out in a 3-column grid.
- `projects.html` — Detailed breakdown of web development and networking lab projects with `#id` anchor navigation.
- `articles.html` — Short technical notes on semantic HTML and basic web security practices.
- `contact.html` — Contact form layout and direct links (Email, LinkedIn, GitHub, Instagram).

## Styling & Layout

All four pages share a single stylesheet (`style.css`) without external CSS frameworks:

- **CSS Custom Properties (`:root`)** for centralized color tokens and typography (`Inter` and `JetBrains Mono`).
- **CSS Grid & Flexbox** for the main 3-column layout, 2-column project/contact grids, and navigation bar.
- **Responsive Breakpoints** (`900px`, `820px`, `768px`, and `600px`) to collapse multi-column grids into a single column on tablet and mobile viewports.
